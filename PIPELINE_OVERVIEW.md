# Pipeline Overview

This repository contains collaborative, exploratory work completed
as part of a Vera C. Rubin Observatory project. The materials are
organized by analysis stage rather than as a single linear script.

The conceptual workflow followed in this project is:

1. Exploratory Data Analysis (EDA)
   - Initial inspection of Rubin-derived datasets
   - Light curve exploration, data quality checks, and summary statistics
   - Implemented primarily in the `EDA/` folder

2. Candidate Variable Star Detection (CVSD)
   - Development of variability metrics and selection criteria
   - Ranking and filtering candidate variable stars
   - Implemented in the `CVSD/` folder

3. Classified Data Retrieval & Machine Learning
   - Retrieval of classified objects and labels
   - Preliminary machine learning experiments and validation
   - Implemented in the `Classified Data Retrieval and Machine Learning/` folder

These stages reflect an iterative, research-oriented workflow rather
than a single production pipeline. Individual notebooks within each
folder represent exploratory or instructional paths taken by different
collaborators.
